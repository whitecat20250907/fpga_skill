# Verilog、引脚与 IP 规则

## RTL 编码

1. 维持工程启用的 Verilog 语法，明确启用 SystemVerilog 的文件才用其语法；自检可独立为 .sv。
2. 顶层负责板级接口、时钟复位和连接，业务状态机另建模块，避免与 system_top、ui_i2c、ui_FDMA、ui_pll 等重复命名。
3. 时序用非阻塞赋值；组合有默认值并覆盖全部分支；避免 latch、隐式 net、同寄存器多驱动。新文件使用 default_nettype none 时在末尾恢复，避免影响供应商代码。
4. 显式处理宽度、符号、截断、地址溢出与计数边界；参数单位写清楚，像素/字节/AXI beat 分开。
5. 各域复位释放同步，保留 IP 复位时序；PLL lock 和 DDR 校准前不允许流量。
6. 单比特稳定控制可用同步器，短脉冲用握手/toggle，多比特用异步 FIFO/握手快照，不能逐位同步数据总线保证一致性。
7. 优先 clock enable，避免逻辑门控时钟；必须生成时钟时用器件时钟资源并约束。
8. 标准 ready/valid 等待接受时保持 valid 和数据，计数在实际传输时增加；FDMA 等封装以代码定义为准。
9. 图像流水线将 DE/HS/VS、坐标、帧号与数据同拍延迟，包含 RAM 读延迟和输出寄存器。
10. 提供有效计数、帧计数、溢出计数、sticky_error 等可证明正在运行的观测。零错误不能脱离测试进度判断。
11. 对新行为自检：UART 忙与队列、I²C ACK/NACK/写等待、FDMA stall/地址边界/数据、图像像素数/行帧边界。加超时、预期比较、非零失败退出码。
12. DDR容量验收应全区先写后读。逐burst写后立即读可能掩盖地址别名；需接受拍数与请求长度一致、等待所有AXI B响应、核对B/R响应与ID/RLAST、错误粘滞和进度超时。全容量轮数与数据量必须真实可观测，不以test_error=0判通过。2026-10-10已用原04v8真实检查器复现bit6别名和3/4短读均假通过，修订在独立demo04_full_capacity_20261010；数字/原生/物理结果分开记录。
13. 新文件加入AL必须保留完整FileInfo，显式CompileOrder。该属性缺失的两个新增RTL在本机TD open_project失败，补入后完整流程继续；audit增加元数据检测，允许原厂重复CompileOrder，不用重排原厂IP作为绕过。
14. 板载EEPROM实测必须先两次读取全容量一致，再将原数据与重复读取、另一独立目录备份全部落盘、fsync并核验SHA。主机只在备份提交后发送ARM，测试工程上电默认不写。测试成功或失败均须安全停止、恢复全部原数据、两次独立全片回读一致，才能切换回正式位流；恢复失败时保留可恢复的服务工程，用已验证备份重试，不能丢弃唯一恢复入口。真实ACK/NACK、写周期等待、完整地址/互补图样、尝试/成功/粘滞错误/完成计数均须可观测；读回图样与计数分开核对。24LC02B为256字节、8字节页、最大5ms写周期；单字节写响应等待10ms，原监督状态机写后20.97ms等待保留。
15. RTC默认只读现有时间，不用示例上电初始化覆盖用户时钟。寄存器指针写不属于时间数据写；初始化须显式参数启用。保留现有12/24小时模式，在FPGA中转换显示；真实NACK与非法BCD必须明确输出错误，不能显示伪造时间。日历/控制/闹钟不写，跨秒原子快照、午夜回绕、连续步进与串口原始字节核对。物理时间连续不证明日期准确或电池保持合格。
16. 异步UART输入的第一级采样不能送组合起始位检测或其他业务逻辑。原vendor五次采样的OR检测使用bit0，不能直接把五级移位当成无一级扇出的同步链。保持vendor IP不动，在输入前加空闲高电平初始化的专用两FF同步器：raw只接第一级D，第一级Q只接第二级D，业务只取第二级Q，两个FF均声明ASYNC_REG。必须检查实际gate连接与PH1布局/布线双寄存器通道、同钟/常开使能/初始化/真实属性，不能只检查RTL或属性数量；物理串口测试与定量MTBF/SDF仍独立验收。
17. 本机TD write_verilog实际忽略文档列出的指定文件名，写<top>_out.v。各阶段调用默认导出后立即将真实产物复制到独立gate/place/route快照，检查存在和长度；保留原native日志，不用改日志标记伪造导出成功。native日志可能GB18030，UTF8失败时按GB18030读取；哈希始终对原始字节。
18. 串口切换位流后先等待、读取并保留初始数据，再用只读版本/CRC/序号握手确认服务。原始旧ASCII遥测不能静默丢弃，首次无回复也不能直接算通过。诊断重加载/重开/控制信号/等待同时变化时不单独归因其中之一；写NVM仍须完整一致备份后才ARM。2026-10-10案例四种只读组合均12响应正确，主机入口增加200ms等待、初始数据记录和状态握手，实际验收以新版完整流程证据为准。

## 引脚与时序

ADC 约束球号和 IO 属性，SDC 约束时钟和接口时序，内部布局布线由 TD 自动完成。

同板同接口复用：从 .al 找实际启用 ADC/SDC/IP → 从 pins.md 定位完整 ADC → 核对端口名称、方向、位宽、位序 → 核对封装与 Bank 电压 → 保留原属性 → TD 后检查 IO/封装报告。

- 不只抄 LOCATION；IOSTANDARD、SLEWRATE、DRIVE、PULLUP、INDEL、PRE_EMP 等都可能影响运行。
- LVCMOS18 不随便改 LVCMOS33。Bank13/J32 选择依据板卡版本、原理图、跳帽位置核对，不盲改。
- LVDS 只列正端时，负端可能被专用差分对占用，不得分给别的信号。DDR 自带 IP 约束，不能再手抄冲突映射。
- 新增接口从连接器 → 网络名 → FPGA 球号 → Bank/专用功能 → ADC/TD 逐项核对，记录来源，不凭邻近引脚猜测。
- 01/02/03 的 I_sysclk、05 的 I_sys_clk_25m、06 的 I_sysclk_25m 为 40 ns；04/06 的 I_ddr_clk 为 10 ns。生成时钟继承 IP 并核对派生报告。
- 05/06 有很宽的 set_clock_groups -exclusive，PLL 时钟实际可能同时工作。新设计做 CDC/时钟关系审查，不能无条件继承为新路径免责。
- 新同步外部接口的 input/output delay 来自外设手册和板级时序，不能填假数值消除警告。正 WNS 不证明接口约束完整。

19. 当前route导出SDF需要保护全部原native文件，包含staged输入、时序和辅助诊断报告。update_timing会执行SDC中的报告输出命令；将旧诊断输出明确重定向到新目录，不改变时序约束，前后核对源/DB/bit及全部原构建文件SHA。CELL/互连结构匹配不证明动态注入覆盖；网表内$sdf_annotate与glbl只保留原一次，真实GSR/相机初始化/输入使能/角/相位/golden和负时序检查仍需实际仿真验证。
20. 最终运行文件交付须取得实际部署的ko与配套工具，逐SHA/长度/目标架构/内核vermagic核对，不能用只有编译SHA的源码包假称二进制已提供。V4L2依赖SGDMA导出符号时保留与原native构建一致的Module.symvers及来源证据。诊断程序与常驻部署文件按真实原路径区分；阶段包可能包含旧失败bit，统一索引须明确当前包内成员并直接读其字节核对，不能只按文件名选择。

## IP 复用与重配置

普通 RTL（UART/I²C/FDMA/部分 ISP）直接例化；PLL/RAM/DDR 保留配置和生成结果；加密文件需兼容 TD 与许可，不做空壳替代。

1. 克隆工程中定位 IPC，记录器件、IP 版本、配置和生成清单，使用当前 TD 对该配置的编辑入口。
2. 比较 IPC、生成 RTL、实例和时钟/资源报告；06 PLL 不同步，不直接 Generate。
3. 列必要改项：PLL 输入/输出频率/相位/反馈；RAM 宽深/端口/读延迟/初始化；DDR 型号/电压/位宽/容量/时钟/PHY/AXI；MIPI lane/类型/速率/时钟。
4. 生成后比较 RTL、netlist、include、ADC、SDC、ROM、仿真模型，更新 .al 顺序与文件集，消除重复定义。
5. 核对接口和延迟，重新仿真、编译、时序检查和实机回归。旧 IP 无法编辑时保留原生成产物，报告具体不兼容环节。

备用/模板 ADC 不一定参与工程，以 IPC fileSet、TD 导入日志及实现报告为准。脚本引用检查不代替这些解析。

## 组合冲突

| 组合 | 处理 |
|---|---|
| UART+RTC | U11 共用，一个 TX 加统一队列，V11 RX 可供命令 |
| EEPROM+RTC | N14/U16 共用，一个 I²C 主机加队列，7 位地址 0x50/0x68 |
| 相机+主板 I²C | 相机 B14/A14 是另一组，不混用 |
| DDR+相机 | 用 06 的 DDR/FDMA，新增主机要仲裁、地址分区和带宽评估 |
| TPG+相机 | 一套 DSI，统一像素域，帧边界切换图像源 |
| 任意组合 | 检查顶层、模块/IP 名、IO、时钟、复位、探针、约束重复 |

缓存占用按 stride×高度×每单元字节数×缓冲帧数计算，读写带宽都计入。确认封装单位后代入，不能将像素数直接作为地址增量。


21. TD Verilog在`default_nettype none`下要求module输入/普通输出端口显式`input wire`/`output wire`；Icarus2012可接受隐式类型不代表TD前端可接受。函数input是变量声明，不能全文件盲目替换为wire。只改module头后核对功能体原字节，保留失败源/日志并用完整独立副本重编译；RTL数字通过不替代TD分析/综合/自己的STA。见chroma_rank42与43和v128证据。


22. V4L2采集计数须在实际streaming中取证。驱动取消DMA时可写soft_reset，停流后读0不能推断硬件没有工作；保留停流前后计数、故障位、原始完整帧和真实源版本/JTAG证据。43首轮因停流后计数0误回退，v2在线读数增长和停流清零已实际复现。
23. 核对实际native用户时钟，不能照抄cam_video_source注释的250–300MHz；43实际125MHz/8ns。generic RAM仿真中的read-before-write不等同primitive字段：实际40颗PH1_ERAM的WRITEMODE_A/B为NORMAL、B禁止写、同实际时钟和显式CE。按真实属性报告，静态映射不替代物理碰撞/像素图案验证。新增40ERAM后不可沿用旧总数≤112的验收器，应逐组检查4×10硬RAM并拒绝缺失/分布式存储反例，保留其余时序/PAD/IO门槛。
