- Python 启动器、接入适配器、场景生成器和源码打包脚本通过语法编译检查。

完整胜利流程验证在新增完成横幅之前进行；后续横幅编译成功，未再次专门走到胜利画面验证横幅。战斗沿用原版随机性，不能保证每次同样回合数或损失。

## 本机性能抽样

Windows 本机，16 个逻辑处理器，游戏窗口 1536×816；每次约 10.3 秒。只统计客户端和服务器，不含 Python 启动器、摄像头和主推理程序。CPU 百分比以一个逻辑核心为 100%，不能直接与全机总 CPU 百分比比较。

| 状态 | 客户端 CPU（单核） | 服务器 CPU（单核） | 合计工作集 | 合计 PrivateMemorySize64 |
|---|---:|---:|---:|---:|
| 静置 | 5.93% | 0.00% | 232.64 MiB | 265.68 MiB |
| 唤起选择，整张地图重绘 | 22.49% | 0.00% | 232.91 MiB | 266.61 MiB |
| 唤起选择，局部重绘 | 11.86% | 0.00% | 233.91 MiB | 267.37 MiB |

采样脚本 `measure-windows.ps1`，原始记录在开发目录 `logs/perf-*.json`。这些是短时抽样，不是平均整局负载或 RK3576 结果；静置项未在局部重绘版本重新测量。
