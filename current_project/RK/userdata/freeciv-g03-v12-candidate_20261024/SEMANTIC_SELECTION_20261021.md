# 基于实际游戏目标的置信与平滑优化

参考用户提供的`D:/EFFECTIVE_MODEL_LOGIC.md`，迁移其时间支持度、领先差距、迟滞和失效思路。吸附对象来自当前游戏实际目标，未加入8×8网格。

## 行为变化

- 模型提供个人标定后的One Euro连续坐标；新的gaze2入口直接使用，不再叠加游戏45ms EMA。鼠标和旧gaze调试入口仍有45ms EMA。
- 每个实际目标维护指数衰减支持量，按源时间间隔更新（180ms时间常数）。空白/边界含糊样本进入总量但不给目标增加支持，避免只看少量“好样本”虚高置信。
- 当前几何胜出目标须占比≥0.60、领先≥0.12、几何区分度≥0.08，连续成立≥120ms且至少3个不同时间戳才可确认。单帧跳点立即撤销确认资格；高亮可以暂留，真实切换须重新稳定。
- 目标距离限制随邻居间距变化，范围36～180像素。单个按钮/交接目标不再吸附整屏。
- 以(kind,id,arg)关联实体，不把候选数组下标当身份。列表重排保持正确目标；目标新增、消失或位置变化超过2像素清空证据。确认前重新收集当前合法目标，回合/玩家/唤起/取消仍重置状态。
- gaze2透传源帧单调时间，重复源帧不积累支持；过期超过250ms/未来帧拒绝。gaze_lost立即清空失效选择，普通注视不执行命令。

核心实现是`semantic_selection.py`（开始页）与`demo_selection.h`（原生游戏），测试对照两者行为。
这里只增加最多64个目标的轻量计算，没有新增摄像头或模型。原个人Ridge/isotonic标定及NPU权重保持。
