使用者与标定

单人直接使用；双人模式下分别选择使用者并完成个人标定。

眼控接管

触发并确认注视 · 目标闪烁原手握拳 · 锁定右手张掌→握拳点击

握拳锁定不会点击。结束后眼动休眠，鼠标留在目标上，直到下次眼控接管。接管手势可在映射中设置；点击是眼控锁定后的附属动作。

轨迹书写

① 握拳准备② 伸出食指③ 保持 0.3 秒④ 画轨迹⑤ 右手握拳执行

支持 0、L、L 反、L 上、L 反上、M、W、Z。右手握拳结束后，识别成功且已绑定便直接执行；无需左手确认。绘制中右手拇指向下取消；置信度不足或未绑定只提示、不执行。

确认、取消与连续操作

任一手张掌 · 准备握拳 · 重复拇指向下 · 撤回

左手仅有重复和撤回：张掌→握拳重复，张掌→拇指向下撤回。右手空闲时相同；右手待确认时握拳执行、拇指向下取消；眼控锁定后右手张掌→握拳点击。手离镜不会清除上一次成功动作，回来可继续操作。

医学演示撤回到该轮操作前的视图。桌面发送当前应用的撤销快捷键；游戏已提交的移动、战斗和回合目前不支持撤回，会明确提示。

触发手势对应功能

伸食指专用于切换轨迹，不再唤醒眼控。眼控接管可在“交互状态”中启动或绑定手势；进入眼控需个人标定。握拳锁定后眼控结束，右手再次张掌→握拳操作锁定点（结构自动聚焦）。菜单打开后可直接比 V 下一项、握拳确认、拇指向下返回。

医学影像 · 简单操作

同一肾脏病例：选择病例 → CT 阅片与标记 → 三维模型和切片并排对照 → 记录观察。模型来自该病例的公开人工分割。

打开医学画面 ↗
看哪个部位眼控接管 → 注视器官、病灶或 CT → 原手握拳锁定 → 右手再次张掌→握拳点击。结构自动聚焦，CT 自动对照；CT 与三维使用同一定位坐标；三维页保留病例切片，点击切片可返回阅片。无需再做聚焦指令。
旋转观察将任意手势或轨迹绑定“旋转 / 停止”。确认后持续转动，操作手张掌即停，离开画面也停（短暂丢帧约容忍 0.6 秒）；再次触发也可停止。HDMI 不设置旋转按钮。
其他操作双手食指连续 3 帧建立距离基准，按距离比例连续缩放；放下任一食指保持，再举起继续。上一页、下一页和复位仍使用手势映射。

不需要设置旋转轴、切片方向或窗宽窗位。旧“聚焦 / 点击”映射统一迁移为“眼控接管”；没有新增第二套眼控入口。映射不会被默认值覆盖。

连续图像工作由软件读取图像并执行相应算子，占用 CPU 计算与内存带宽。在图像流中完成已迁移算子，向 RK 交付模型图像；减少重复全帧处理。
实时性软件阶段受线程调度和应用负载影响。硬件像素处理不依赖 Linux 线程调度；整条链仍受相机节拍、FIFO 背压、DMA 和模型影响。
灵活性交互规则、目标选择、应用操作方便更新。固定图像操作适合流水化；动态旋转 ROI 等仍由 RK 处理，不为迁移而迁移。

查看历史基线与测量边界

2026-10-23，RK3576 原 C 精确 3×3 缩图（1080P → 640×360），120 次样本，中位数 3.756 ms / 帧，范围 3.648–6.142 ms。该结果是历史 CPU 算子基线，不是当前软件全链路耗时。

独立 FPGA“缩图 + 裁剪 + 镜像”仿真曾记录约 518,402 周期 / 帧；125 MHz 假设下约 4.147 ms / 帧。该独立工程当时全工程时序未签核，且工作范围不同，不能与 CPU 数字直接相除作为上板加速比。
