## 当前链路

个人标定（ridge_iso）→One Euro平滑→按屏幕宽高归一化/限制到0～1→按当前应用真实目标提名单帧候选→时间加权投票→条件满足才更换已选目标→输出该目标中心。沿用当前医学结构、按钮、游戏与桌面控件作为区域，不另加固定8×8格。

- 最近最多12个有效结果；最新权重1，随后0.85、0.85²……。
- 票重第一的候选连续领先4次有效更新、票重占比≥60%、与第二名票差/总票重≥12%，才确认目标。首次选中也需连续4次。
- 条件不足保持已选目标。单次异常跳变、边界往返不直接推动鼠标。
- 每个源时间/序号只投一次；100Hz引擎tick与握拳时重复调用更新，不额外加票。
- 无效眼动不投票，也不新产生鼠标移动；连续领先计数重置。有效源间隔超过500ms时重建票窗，仍保留应用中存在的已选目标等待新证据。
- 新眼控接管、应用/模式/硬件代次变化清空投票；目标删除、位置失效或动作身份改变不能继承旧票。
- 每帧空间提名沿用目标矩形/中心距离与提供方置信度，关闭该调用中的旧距离迟滞，避免再叠加一套切换门限。目标时间置信度表示票重占比，不等于模型的真实精度概率。
- HDMI初次稳定目标时显示0～4进度；已有目标继续显示当前已选目标。握拳仍按原流程结束眼控并冻结，后续手势点击/结构操作不改变。
