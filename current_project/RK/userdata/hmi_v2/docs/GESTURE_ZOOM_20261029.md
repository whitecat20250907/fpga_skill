## 缩放取代旧放大/缩小

1. 双手食指竖起，不需要前置握拳。连续三个不同的新源帧都识别到本人的左、右食指后，记录第三帧的指尖距离 x，同时保存当前画面大小 S。
2. 后续两指距离为 y，画面大小为 S×y/x。距离在 640×360 图像坐标中计算，避免归一化横纵比例不同导致误差。没有沿用旧的每次乘 1.25 或旧缩放上限。
3. 任一食指放下或离镜，停止更新，保持最后大小。再次举起三帧，以当时距离和当前大小重新开始，可连续续调。
4. 双指准备/缩放时优先占用双手，取消尚未提交的普通手势和轨迹；单指轨迹不能同时录入。右手结束缩放的拳不会自动变成下一次手势启动。
5. 整段缩放只产生一个应用动作及一份撤回快照；每帧更新通过最新状态传给应用，不逐帧排入动作队列。重复上次缩放会再次应用最后一次的相对倍率；撤回恢复该次缩放前的视图。
6. 这是医学视图的固定双手操作，不需要配置两个新的放大/缩小映射。旧 demo.zoom_in / demo.zoom_out 入口移除，已有对应映射迁为空，其他映射不变。左手“仅重复/撤回”的规则新增双手食指缩放这个明确例外。

眼控接管、右手握拳锁定、右手张掌握拳点击，以及左右手重复/撤回的规则保留，见 GESTURE_CHAIN_20261029.md。

## 一条可走通的演示主线

病例 01/02/03 对齐排列，每张卡片包含该病例 CT 与三维预览。选择其一后始终围绕同一份 CT、人工分割和坐标进行复核。

- 阅片：大切片居中，其他方向切片在左，同病例三维预览在右。选择部位、查看标注对照、阅片/缩放后，标记当前疑点。
- 三维对照：大模型在右，两张对应切片始终在左。旋转、选择模型部位、双指缩放；当前定位点和切片十字位置使用同一组坐标。对照不清楚可直接点击切片返回阅片。
- 判断：支持当前定位则确认；不支持就回到切片重新检查。没有为了剧情编造误诊、病理类型或自动诊断。
- 观察记录：展示定位切片、同病例模型及观察位置。已经确认的记录不再提供重复的确认按钮。记录仍为当前会话，不冒充已写入医院患者档案。

手势控制的旋转/翻页不重复做成 HDMI 控制按钮。眼控目标是病例、影像、解剖部位和观察内容；所有目标矩形由后端与页面共用，且留出右下角操作窗。
