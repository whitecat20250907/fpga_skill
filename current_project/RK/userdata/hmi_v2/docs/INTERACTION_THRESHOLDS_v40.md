# 交互门槛审查与流畅性调整 v40

本轮按实际链路逐层检查，不将模型分类第一名等同于已执行动作。新的集中配置为 config/interaction.json，由 core.config.load 合并到所有使用者；板级配置、冻结权重和用户 bindings.json 不覆盖。

## 真实问题与验证

v37真人记录：L=0.9758，约5.9秒后脸部track变化使待确认取消。v38去除未登记单人非空间操作的该关联。

v38真人记录：左手张掌连续0.50–0.64、随后握拳连续0.80–0.87；旧0.70松手门槛使整个确认卡住。271帧实际手部消息已提取为 tests/fixtures/left_confirm_v38.json（无图像/关键点），新流程回放只产生一次确认；包括同手拒绝、预先握拳拒绝、已经张掌无需重做、缺帧/换track、人员/模式切换的反例。

较低门槛下的真人误触率和双人四手仍需现场验收；离线回放和单元测试不冒充真人通过。新版本没有改MIPI布局、FPGA位流或DMA所有者。
