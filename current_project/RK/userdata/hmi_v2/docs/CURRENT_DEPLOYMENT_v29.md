# 当前部署与资源实测（2026-10-25，v29报告）

## 可以使用的当前版本

八项服务运行，医学演示在HDMI前台，游戏开始页在后台。电脑控制台为 http://127.0.0.1:8786/ （已有授权隧道）；从菜单选择游戏或医学演示并确认即可切换，未标定时允许明确打开应用，但手势/眼控动作仍受标定和新鲜度约束。用户已确认F5的MIPI新布局正常显示。

当前软件：C采集v23、交互v24r2、HDMI重绘v25、网页命令v27、应用绑核v28。唯一采集PID105104及boot/epoch未变。FPGA仍为F5，位流SHA256 cebc42b4b8ba689419b25d761d924fe30bd40cfdc3ab8a3fbf98ea5a216ba271；仅SRAM，没有写Flash。322个冻结算法/权重/协议文件板端逐项SHA256通过。

## 本轮已修复

1. HTTP请求在主循环取时间之后入队时，被旧时间误判为未来而丢弃：改为每次出队后重新取时间，保留过期拒绝，不自动重发。
2. 游戏、医学浏览器及启动辅助进程均使用配置CPU0–1，避免占用CPU2–3的DMA轮询核心。原launch.py、模型与驱动分工未修改。
3. 未标定时明确菜单选择可打开应用；游戏开始页按实际PID工作目录识别，再选回同一窗口。HDMI静态缓存漏处理Expose导致的空白提示窗也已修复。

板端70项相关回归通过；15次真实菜单选择、10次前台应用检查、所有已观察应用线程CPU0–1、无应用动作历史增量均通过。X11提示窗/菜单点击穿透与3次真实Expose重绘证据见v25报告。失败日志保留。

## 同一十分钟窗口的实测

场景：无人、医学页前台、游戏开始页后台；没有运行游戏战斗，也不是真人模型有效输出帧率。

| 项目 | 均值/结果 |
|---|---:|
| 同源模型共享环发布 | 40.83 Hz |
| CPU八核归一化使用率 | 53.25%，P95 56.33% |
| NPU0动态忙碌率 | 12.97% |
| NPU1动态忙碌率 | 0.14% |
| 采集/服务持续性 | 600.02秒采样，健康窗口通过，owner/epoch不变 |
| 有完整包尾的短错误包 | 52个；校验、丢弃并恢复后继续运行 |

空场景MGaze没有正常双眼输入，NPU1低负载不代表浪费，也不能据此推算两人四手负载。十分钟仍有52个错误包，**绑核没有消除溢出，DMA不能判为完全修复**。一分钟7→1的先前对照只是短测，不作为长期改善保证。

原F5/v23两分钟同窗独立1080P预览18.24Hz、模型40.95Hz；本次十分钟没有独立采集预览帧率，不能冒用旧值。预览FIFO历史高水位5390字、该十分钟blocked-valid计数增量0，因此不直接把8192缩到2048。

## CPU / NPU / FPGA分工与资源

| 执行端 | 当前任务 | 资源口径 |
|---|---|---|
| FPGA | IMX415接收/ISP、独立1080P预览、640×360共享缩图、128²人脸与192²手掌输入、BND1打包、MIPI UI | 静态占用，不是动态忙碌率 |
| RK CPU | 唯一DMA/BAR所有者、共享环、ROI裁剪/旋转与输入组织、后处理/跟踪/标定/交互、HDMI/网页/应用 | 上表53.25%含内核与应用；不能只把模型进程CPU相加 |
| NPU0/1 | 人脸检测/478点、MGaze、手掌/21点/静态手势、8类轨迹RKNN前向；Blendshape关闭 | face mask1、MGaze mask2、hand AUTO0；0表示自动选核 |

| FPGA资源 | 当前F5 | 占比 |

| LUT6等效 | 41489 / 64320 | 64.50% |

## DMA判断与剩余范围

当前采集会话抽样记录的12次错误均为41008字节、errno0、FPGA status8，复位前模型FIFO overflow=1。RTL对应源输入空闲超时后封尾。证据支持“支路溢出→源包不完整→封尾短包”的错误路径；尚不能定位造成背压的具体PCIe/内核时刻，也没有证明无EOP或在途DMA异常的恢复。见DMA_DIAGNOSIS_v28.json。

F6 CNR候选只减少过配行缓冲，模块逐像素对比通过，完整物理中间值239 ERAM；最终原预算建立/保持仍在优化，**没有替换当前F5**。完整CDC/IO、实板画质/吞吐/停机仍待验收。其他P6（FIFO回收、诊断裁剪、1080P变体、光栅打包、AE、真实张量PiP、热力图、BND2 ROI）、独立compat-up尚未完成，保留关闭或原实现。

真人一人/两人四手、头部显示、分别标定、八轨迹/误触、实体键与游戏完整联动仍待实测。全部范围保留，当前不宣称总任务完成。操作流程见USER_GUIDE_CURRENT.md；当前状态以本报告为准，附件中的旧“未上板/CSR=false”只描述当时交付。
