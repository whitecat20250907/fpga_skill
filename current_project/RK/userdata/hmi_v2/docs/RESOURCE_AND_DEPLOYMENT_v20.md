# 已部署模型、并行测试与资源统计 v20

2026-10-25。本报告区分实际视频链路、固定输入真 NPU 并行测试、FPGA 静态资源。当前无人入镜，不能用固定张量吞吐代替真人两人四手的端到端帧率、精度或误触结论。

## 当前分工

摄像头 → FPGA ISP、128²人脸/192²手掌输入分支及同源模型平面 → 唯一 C 所有者 → 三槽共享环 → 眼脸/手部服务 → 交互引擎 → 应用适配器。独立1080P预览由同一所有者另一个 memfd 提供，未开启第二个摄像头所有者。

FPGA 负责原 ISP、流式图像操作、PCIe传输和 MIPI 图形。CPU 负责驱动/接收校验、共享环、ROI变换、网络后处理、跟踪与归属、标定/滤波、交互和应用。全部下表神经网络前向为 RKNN NPU；478点网络仍在运行，空场景没有有效头部关键点不等于关闭模型。Blendshape 关闭。

核掩码1=NPU0，2=NPU1，0=AUTO；0不表示CPU。现用人脸检测/关键点固定NPU0，MGaze固定NPU1，手部检测和两个ROI工作器AUTO。两个ROI工作器是独立上下文，不并发调用同一个RKNN实例。

## 真实输入链路

保留1920×1080预览。v18预览请求预算20Hz，20秒实测模型环40.97Hz、预览发布17.95Hz；此前连续请求预览时分别29.98/14.40Hz。模型单路约60Hz，不能当作两路并发成绩。原>50Hz模型性能门限仍未达到。

v18连续600秒空场景：模型共享环40.93Hz，CPU八核归一化平均37.57%/P95 38.61%；NPU0平均12.15%/P95 13%，NPU1平均0.61%/P95 1%。质量窗口健康率100%，无环序号回退。CPU3平均99.12%、CPU2平均67.08%，对应活动的SGDMA轮询线程；驱动未改。眼脸/手部状态约10.2/11.7Hz不是有效眼动或四手识别率。有效标定眼动0。

## 真NPU并行工作负载

固定合成输入，真实模型前向，每轮都执行检测器。脸链每人包含478点与MGaze；手链每只手包含21点、特征嵌入和分类，最多两个ROI工作器。双人用2张脸+4只手，并强制每轮执行两次MGaze；实际业务当前使用者选择可能减少MGaze次数。未包含图像裁剪、NMS、跟踪、标定和应用延迟。GestureNet8是轨迹完成时的事件推理，不放入持续循环。

v1每项15秒，v2每项20秒；仅暂停两个模型服务，C采集、预览及其余服务继续，因此CPU值包含这些后台工作。轮数计量包含主机提交/拷贝/等待，不是纯NPU内核时间。测试结束八项服务恢复，C所有者PID44695不变。

## 当前板上FPGA的静态资源

当前 SRAM 基线SHA256：9e82d8cd50510a8480afe6a49f0e3cd61ef3194334fe225d65fb7bd7265c0e59。对应原发布清单中的位流、物理资源报告SHA逐一匹配。

| 资源 | 使用/容量 | 比例 |
|---|---:|---:|
| LUT6等效 | 39,969 / 64,320 | 62.14% |
| 物理slice | 46,131 / 64,320 | 71.72% |
| 寄存器 | 43,734 / 128,640 | 34.00% |
| ERAM | 264 / 272 | 97.06% |
| DSP | 83 / 240 | 34.58% |

这些是当前位流综合布局后的静态占用，不是每秒动态忙碌率；不得与CPU/NPU百分比相加，也不得把LUT6等效与物理slice相加。各层次子模块计入父模块，不能重复汇总。最大限制仍是ERAM和关键路径，不是DSP不够忙。

F5是新布局/成绩卡/启动修复候选，F6再叠加CNR行深优化，两者独立构建。F5已见最终建立+0.036ns、保持+0.020ns，仍须完成最终产物/CDC审查；F6尚在编译。CNR模块50→25 ERAM证据不等于整板已回收25块；本报告不将候选资源替换当前板上数字。
