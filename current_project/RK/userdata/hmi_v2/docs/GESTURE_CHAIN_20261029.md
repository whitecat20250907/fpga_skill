# 手势链路手册 · v92 · 2026-10-29

## 先看操作

左右按识别结果中的本人左右手区分。单人默认直接操作；双人模式继续使用当前人的手部归属。

| 场景 | 操作 | 结果 |
|---|---|---|
| 右手普通手势 | 握拳启动 → 比 V／竖拇指等已绑定手势 → 右手握拳 | 执行该手势映射，HDMI 显示实际回执；无需左手 |
| 右手轨迹 | 握拳启动 → 伸食指 → 倒计时后画轨迹 → 右手握拳结束 | 识别通过且已绑定就直接执行；无需再确认 |
| 左手快捷键 | 张掌 → 握拳 | 重复当前应用、当前使用者的上一次成功应用动作 |
| 左手快捷键 | 张掌 → 拇指向下 | 撤回上一次成功应用动作 |
| 右手空闲快捷键 | 张掌 → 握拳／拇指向下 | 同样重复／撤回；眼控锁定后的握拳特例见下文 |
| 静态手势待确认 | 右手直接拇指向下 | 取消待确认手势，不执行、不撤回旧动作 |
| 轨迹正在画 | 右手拇指向下 | 取消本次轨迹；晚到的分类结果不执行 |
| 任一手张掌后拇指向下 | 包括正在确认、选目标或画轨迹时 | 结束当前待办，再撤回已执行的上一步；没有历史则只取消 |

左手不再启动普通手势、轨迹或确认右手结果。比 V 等动作的实际功能以电脑控制台当前映射为准，本轮保留已有映射。

**张掌前缀属于快捷键。** 想开始新的普通手势／轨迹时直接握拳；如果先张掌再握拳，空闲时会按重复处理。程序不猜测你握拳以后才准备比 V 的意图。

## 眼控接管

1. 右手握拳 → 做映射到“眼控接管”的手势 → 右手握拳确认，开始眼动选目标。也可用已绑定轨迹，在结束握拳时直接进入。
2. 看目标；系统选择可吸附目标并提示。右手松开启动时的拳，再握拳，结束本轮眼控并锁定目标。
3. 锁定的这一拳只锁定，不点击、不重复旧动作。保持拳不会不断触发。
4. 右手张掌 → 握拳，点击锁定的目标。左手仍只执行重复／撤回。
5. 再次触发眼控接管才开始新一轮目标选择。其他已绑定应用动作按原有锁定目标策略执行。

右手在眼控选择阶段的拳优先锁定；在静态手势待确认、菜单等状态中，拳优先完成当前确认，不与重复同时执行。

## 动作历史

- 只有应用返回成功回执才记录；失败、拒绝、超时不会覆盖上一次成功动作。
- 手离开几分钟、重新入镜或手部 track ID 改变，不清除历史。新手势仍需重新张掌准备，每次张掌只产生一个后续快捷动作。
- 各应用、单／双人模式、当前人分别记忆；切回原应用可使用该应用的历史。双人重新登记不同人不会继承上一人的历史。
- 记录最近一次成功应用指令与最多 64 项撤回历史。重复使用新动作 ID，并等待新的执行回执；没有无回执自动重发。
- 交互引擎重启或 FPGA 硬件代次改变会清空内存历史；这里的长期记忆指离镜后仍保留，不是断电持久化。
- 标定、应用切换、人数切换、眼控入口等系统管理命令不进入应用撤回／重复历史。它们仍可通过手势映射直接调用。
- 医学视图可恢复动作前状态；桌面撤回是在原窗口校验通过后发送 Ctrl+Z，效果由对应软件决定。游戏已提交的移动、战斗、回合目前不能真正逆转，会明确拒绝，不能把该限制当成已实现撤回。

## 冲突与退出

两手同时发快捷操作时撤回优先，同一轮最多提交一个动作。正在等待应用回执时不提交重复副本。右手候选不唯一时暂停该轮操作；不能把另一人的右手当成当前操作手。

待确认静态手势可以直接用右手拇指向下取消，15 秒无操作也会退出。右手跟踪 ID 改变后，只要仍是唯一右手，确认可以继续。轨迹结束后的 RESULT 状态不会重新开始记录；取消、撤回后的旧分类／旧录制消息被代次检查拒绝。

当前配置使用短保持而非长时间举手：启动拳约 0.12 秒，普通确认拳约 0.18 秒，眼控锁定拳约 0.15 秒；至少两帧有效观察。轨迹倒计时保留 0.3 秒。它们是识别保持参数，不是端到端延迟承诺。

## 数据链路

同源图像 → 手部 NPU 服务 → 手势／轨迹消息 → 唯一交互引擎按状态和左右手分派 → 应用策略校验 → 适配器执行 → 成功／失败回执 → 更新历史及 HDMI／网页／MIPI 状态。

视觉进程不直接点击。MIPI 保持你确认过的原布局，本轮没有更换位流或改采集链路。478 点展示仍在基础功能页面。

## 本轮验证边界

最新代码已部署；ARM 隔离回归 104 项通过，涵盖长时间离镜、左右手限制、静态确认取消、轨迹两种消息到达顺序、眼控锁定不连击、双手冲突、旧代次拒绝、失败回执不污染历史及双人登记时的归属。

板上核验了部署文件 SHA256、8 项服务、连续状态更新、医学应用实际启动回执和原生 HDMI 窗口。没有向实时模型总线注入虚假手势。真人尚未入镜，真实左右手识别稳定性、手势舒适度与误触情况仍待测试。

建议真人顺序：右手握拳→V→握拳；右手画轨迹→握拳；左手张掌→握拳重复；左手张掌→拇指向下撤回；右手同样快捷键；离镜后返回再重复；最后眼控锁定及点击。待确认 V 也单独试一次右手拇指向下取消。
