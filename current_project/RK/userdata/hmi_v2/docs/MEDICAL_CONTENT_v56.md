# v56 医学内容与简化操作

本轮按最终用户要求，HDMI 只提供医学内容目标，删除翻页/缩放/旋转/复位等重复操作按钮及其吸附目标。上述动作只保留在手势动作目录与已有管理 API，管理 API 用于电脑调试，不是 HDMI 候选。

## 医学

- 原心脏、脑、肾脏三页保留；新增 KiTS19 case_00000 同病例 CT + 人工分割表面重建。前三页每页六个结构，病例页七个医学内容目标。CT 展开与病例说明展开时只发布当前可见内容矩形，隐藏的目标不参与吸附。
- 选择病灶/患侧肾/对侧肾自动对照三个方向切片。点击 CT 展开，第二次点击返回；病例说明提供数据来源与标注含义，不生成诊断结论。
- 统一“点击目标”：医学结构自动聚焦。旧 demo.focus 映射兼容为 demo.click；不覆盖用户配置文件。取消独立聚焦、旋转轴、前后切片、窗宽窗位等映射选项。
- 旋转是一个开关：确认后持续约18°/秒，操作手张掌约120ms停止，离开约600ms停止；同侧短暂重获跟踪可继续，另一手张掌不停止。手势控制手通过引擎动作参数传到应用；停止只观察引擎筛选后的有效手，应用不采集或推理。
- 绘制最大约30次/秒，静止时停止三维重绘；CT 仅在部位/展开变化时重画。该上限是显示绘制预算，不改变摄像头或模型 FPS。

3D 网格来自原分割，显示 CT/标签同为 XYZ C-order 的 RAS 网格，171×171×204，间距2.759765625×2.759765625×1.5mm。三维显示采用 R,S,-A 坐标。不是把无关 X 光片配到模型上，不表示临床诊断验收。
