# F5 + v23：采集计数和正常重启

2026-10-25。当前 FPGA 仍为用户确认正常显示的 F5；未修改位流、DMA、调度、模型、配置和帧率预算。
v23 只增加唯一 C 所有者的 STAT 只读字段，以及 tools/capture_profile.py；Python 不打开硬件节点。

原 F5 运行代正常停止，累计 93,279 个模型发布、43,393 个预览采集、5 次完整封口 status8 错误包、9 次软件队列丢弃；error/cleanup 和独立清理诊断均为0。硬件无在途签核仍为 false，不能因此宣布所有 DMA 故障已根治。

板端 ARM 编译使用 -Wall -Wextra -Werror，面板/设备打开/清理/接收诊断/预览预算/快慢 CRC 可执行回归通过。新 native SHA：99b6dd138b2782ab2c07055811c507c4e101551e7d4a11ea196454328b102a67。八项服务正常重启；交互 v22 的51项ARM结果属于前次实现证据，不冒充本轮全部重跑。

新代120.001秒只读采样：模型发布40.9499 Hz，独立1080P预览发布18.2407 Hz；预览 FIFO 从硬件复位起峰值1个128位字，valid且未ready周期增量0。模型支路增量：source7201、complete6466、abort_frames0、overflows0、packet_aborts1、drops2286。各计数定义不同：TDM/信用未准入产生的 drops 不能等同于坏图；packet_aborts 的一次错误也不能删掉后说所有错误均0。

顺序 BAR 读取不是原子快照；最长连续背压尚无寄存器，启动/压力场景尚未覆盖，不能据峰值1直接批准8192→2048。预览序号通过原非阻塞锁只读64字节头，没有完整图像复制。

F6 CNR物理映射中间结果239 ERAM，最终原约束时序/bit/上板尚待完成；不得把239作为当前板上占用。当前FPGA静态资源和十分钟CPU/NPU结果仍见 F5_DEPLOYMENT_AND_RESOURCES_v22.md。compat、其余P6、完整CDC以及真人单人/双人四手验收继续保留。
