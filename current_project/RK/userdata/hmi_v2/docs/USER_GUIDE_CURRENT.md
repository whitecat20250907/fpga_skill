# 当前操作说明 v58

## 操作分工

HDMI 只展示医学内容与交互回执。翻页、放大、缩小、旋转、复位由手势完成，不显示成 HDMI 按钮，也不进入眼控吸附列表。电脑控制台负责切换应用、标定与修改映射；MIPI 保留现有算法展示。

1. 普通手势操作无需眼动标定。眼控首次使用先标定；单人无需登记。
2. 触发并确认“眼控接管”，注视器官标签、病灶、CT 或其他应用真实目标；候选闪烁。
3. 原操作手松开后握拳锁定。眼动结束，鼠标留在所选目标，不自动点击。
4. 做绑定到“点击目标”的手势并确认。医学结构自动聚焦，CT 自动定位到该部位；CT 内容可展开查看，病例说明可展开阅读。再次点击相同内容可返回。没有第二个“聚焦”映射入口，旧 demo.focus 映射在读取时兼容为 demo.click。
5. 想选其他内容，再触发眼控接管。已锁定点不要求持续眼动或持续看到人脸。

## 手势与旋转

静态手势：握拳准备 → 比 V / 竖拇指 → 原手握拳确认。

轨迹：握拳准备 → 食指保持倒计时 → 画轨迹 → 原手握拳结束 → 另一只手张掌后握拳确认。已张掌入镜不必再重做张掌。

将所需手势或轨迹绑定“旋转 / 停止”，确认后模型持续水平旋转，约 18°/秒。操作手张掌约 0.12 秒即停，离开约 0.6 秒也停；短暂识别丢帧保留容忍。另一只手张掌不会停止它。轨迹的操作手指画轨迹的手，另一只手只负责确认。再次触发旋转也可停止。停止后保持当前角度，不自动回正。

其他医学动作只有上一页、下一页、放大、缩小、复位视图。没有旋转轴、切片翻层、窗宽窗位等手动设置。映射以电脑控制台当前值为准，不能照搬旧版本的默认手势表。原映射文件保持；新增旋转可选项不会强行覆盖已绑定手势。

确认手无限次张掌/握拳重复命令仍是历史待办，当前不把它描述为已完成。旋转开始/停止是本轮单独实现的持续动作。

## 医学内容

四页：心脏、脑、肾脏解剖参考，以及 KiTS19 case_00000 肾肿瘤 CT 病例。前三页每页六个解剖部位。病例页可选择病灶、病灶所在肾脏、对侧肾脏、轴位/冠状位/矢状位 CT 、病例说明、影像对应和标注图例，共九个内容目标。

病例的 CT、人工分割与三维重建来自同一份数据，使用同一 RAS 坐标。三维表面呈现公开标注；不是设备预测的病灶。显示 CT 经 3 倍步长采样，属于教学交互演示，没有新增病理结论。点击结构自动更换三方向切片中心；无需手动选择切片层数。

## 游戏与实体键

游戏保留原生规则和五个主要动作。吸附目标在两侧每页最多四项，底部“更多目标”只负责翻候选页；地图编号是位置注释，不是额外吸附点。招募的四兵种仍可逐页选择。游戏翻候选页和医学翻内容页不是同一个动作。

MENU 短按菜单，长按 2 秒暂停交互；VOL＋短按下一项、长按 1.2 秒启动游戏；VOL－短按确认、长按 1.2 秒启动医学演示；ESC 短按返回、长按 1.2 秒切换单双人。PWR、RESET 不作为操作快捷键。

单人标定在短暂丢脸或跟踪号变化后保留；换实际操作者需要重新标定。双人仍分别登记与标定。交互引擎重启会清除当前标定和锁定目标；本次部署后需重新标定眼控。手势映射保存后实时生效，不需要重启。

## 医学图文入口 v58

三张 CT 均可像链接一样点击打开；再次点击当前影像返回总览。展开后下方仍可点击另外两个方向，也可切到病例说明、影像对应、标注图例。选择左侧结构时回到三方向对照，并定位对应部位。图下层数是当前对照切面的注记，不是新增切片按钮。
