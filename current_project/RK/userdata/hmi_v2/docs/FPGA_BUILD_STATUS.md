# FPGA 本轮本地构建结果

工具：本机 Tang Dynasty 6.2.2.200067 / Release_2026.1_SP2，器件 PH1A90SEG324，speed 2。本轮从源码开始综合、布局、布线及位流生成；旧路径引发的中断从本轮自己的布局检查点继续，保留原始失败日志、检查点 hash 和恢复脚本。它不是一次连续无中断调用，也没有使用历史工程的旧位流替代结果。

|---|---|---:|---:|---:|---:|---:|---:|

只有 SWNS>0、HWNS>0、STNS=HTNS=0 并完成输出检查的构建才收录位流。位流 SHA256、资源、源文件核对和全部精简报告位于 FPGA 工程 `build_evidence/summary.json`。原始 DB、门级大网表、崩溃转储保留在本机工作目录 `reports/`，不进入压缩交付包。

## 跨时钟与验收边界
新增 CSR 采用稳定 mailbox、三拍 toggle/ack，C 侧先提交 CSR 再发送对应 HFT2 包；异步时钟及空白期提前到来的仿真通过。原工程的源配对、时钟监控和 ASYNC_REG 属性检查随真实构建执行。上述检查不等价于完整 CDC/MTBF 签核。

整合版布局将同一 PCIe user_link 复位驱动 DFF 复制到两个位置，v3 检查因网络名不同而拒绝。本轮新增 v4 检查逐项验证复制 DFF 的 D 输入、时钟、复位极性/源、使能、禁用同步复位、GSR 默认值完全一致，并验证改错 D/时钟/复位极性时仍拒绝。所有 16 个计数器的复位仍必须来自对应本地第二级，6 处时钟监测器入口约束保持精确 pin 范围，没有扩展成整组时钟 false-path。原拒绝记录、v4 结构证据及反例检查随包保留。

新增 HMI 同步器在综合阶段六个寄存器均有 ASYNC_REG，布局打包后部分末级丢失属性。本轮根据真实网表四条私有 Q→D 边定位两条三拍链，精确恢复源声明属性并检查没有改动其他寄存器；随后重新布线。图识别结果与恢复后的严格属性检查分开保存，图识别本身不计为 ASYNC_REG 通过。

本轮在独立进程加载自己生成的基线 routed DB，运行 TD `report_mtbf -file native_mtbf.txt -cdc_sink_pin`。工具在 update_timing 后崩溃（exit 1），没有生成可验收的 MTBF 报告。日志还包含部分 ERAM 异步复位来源、IP 时钟覆盖，以及相机 I²C / ChipWatcher 调试时钟使用局部布线的警告；保留在 build_evidence，不把它们写成已解决。独立报告过程不改已完成的 routed DB 或位流。

本次没有上板、没有 SRAM/Flash 下载。正时序不等价于物理屏幕、PCIe 连续 DMA、复位恢复或真人交互验收；默认 CSR 开关仍为 false。完整新布局、P6 资源回收/AE/PiP/ROI 仍按 P6_REPORT.md 的边界保留。
