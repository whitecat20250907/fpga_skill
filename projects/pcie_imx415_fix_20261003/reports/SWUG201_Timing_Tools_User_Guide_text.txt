1 概述 
本文档主要介绍了TangDynasty®（以下简称TD）软件中时序约束工具Timing Wizard 和静态时序
分析相关的各类报告Check-Timing Report、Timing Report、Logic Level Report、Clock Tree Report、
Clock Intersection Report 的界面操作和使用。这些文档为用户提供设计系统的时序约束指导，通过
静态时序分析中帮助用户评估系统的时序性能是否达标。 
2 时序约束工具 
TD 软件的时序约束工具Timing Wizard，是用于辅助用户对设计进行时序约束的工具。用户对设计
进行时序约束有两种方式： 
 
第一种，通过添加SDC 文件，SDC 文件可用户新建并写入SDC 命令或添加已有SDC 文件； 
 
第二种，通过Timing Wizard 界面设置时序约束。 
本文档仅详细介绍如何通过Timing Wizard 进行时序约束设计的方法。 
2.1 Timing Wizard 启动方式 
当Flow 运行完成Syn Opt 的Optimize RTL，并执行Open Run 操作后，才可打开时序约束界面
Timing Wizard，否则该界面保持置灰即不可操作状态。 
鼠标点击TD 主界面菜单栏Tools，在下拉菜单中点选Timing Wizard。如下图所示。

2.2.1.2 Create Generated Clock 
Create Generated Clock 设置界面，用于定义一个派生时钟，设置派生时钟Generated Clock 与
主时钟Master Clock 的频率与相位（边沿）关系，并生成相应的SDC 命令create_generated_clock。
Generated Clock 属于Master Clock 所在的时钟域，在时序报告中也将具有和 Master Clock 相同的
时序起点。 
点击Create Generated Clock，进入其设置界面，如下图所示。 
 
图 2-14 Create Generated Clock 设置界面 
界面中相关参数所设值必须保证正确有效，否则设置界面的Apply 按钮置灰，无法进行创建。相关
参数设置如下所示： 
 
Clock Name: 指定派生时钟名，不可缺省。 
 
Master Pin：指定生成时钟的驱动时钟源点，即Master Clock 所在的源点，该源点可以是物理
上存在的任意时钟节点，点击 Master Pin 的下拉菜单，系统会列出设计中所有已存在的时钟节
点，选择需要的时钟源点即可。 
 
Master Clock：指定时钟源点上的驱动时钟，同一个时钟源点可能会被创建了多个不同时钟。当
时钟源点上存在多个不同的时钟时，需要加上-master_clock 以及-add 选项；当时钟源点上只存
在一个驱动时钟时，该选项可以省略。注意一旦存在-master_clock 选项，必须加上-add 选项。

 
Source Objects：用于指定生成时钟的约束对象，可通过单击右侧search 符号，在弹出的窗
口中选择需要的时钟节点，可通过get_ports、get_pins、get_nets 进行过滤筛选。 
 
Add：指定对同一生成时钟约束对象进行多次约束，可以约束为不同的频率、不同的相位或不同的
占空比。如果命令中存在-master_clock 参数，却省略-add 参数，会报USR-8109 的CRITICAL-
WARNING。注意一旦存在-add 参数，必须加上-master_clock 参数。 
 
By Clock Frequency：如果勾选此项，则基于时钟频率关系的方式设置生成时钟，将可通过分频
参数Divide source clock frequency by 或倍频参数Multiply source clock frequency by 来
设置，并配合Phase 参数调整相位。与By Clock Edges 设置存在互斥关系。 
 
Divide source clock frequency by：指定生成时钟和驱动时钟的分频系数，数值为正， 默认值
为1.000，数据格式支持小数点后三位。与Multiply source clock frequency by 设置存在互斥
行为。 
 
Multiply source clock frequency by：指定生成时钟和驱动时钟的倍频系数，数值为正，默认
值为1.000，数据格式支持小数点后三位。与Divide source clock frequency by 设置存在互斥
行为。 
 
Duty Cycle：配合Divide source clock frequency by 选项使用，用以调节生成时钟占空比，默
认值为50 即50%，取值范围是0～100。 
 
Invert waveform：用于配合By Clock Frequency 选项使用，勾选该选项，为将生成时钟的波形
反转。 
 
By Clock Edges：如果勾选此项，则基于时钟相位关系的方式设置生成时钟，将可通过时钟沿对
应关系参数Edge List 和时钟沿偏移参数Edge Shift List 来设置。与By Clock Frequency 设置
存在互斥关系。 
 
Edge List：指定生成时钟的沿与驱动时钟的沿的对应关系，界面中三个框，分别指定新生成时钟
的第一个上升沿，第一个下降沿，第二个上升沿对应驱动时钟的相应边沿。 
 
Edge Shift List：该选项仅在-edge 选项设置正确才有效，用于指定生成时钟的沿与驱动时钟的
沿的偏移关系。界面中三个框的所设值为整数，单位为ns，该值的正负表示偏移的方向，为正时
向右偏移，为负时向左偏移。 
 
Phase Value：指定生成时钟波形的相位移动，默认值为0，取值范围是0～360 之间，数据格式
支持小数点后三位。

2.2.4.3 Set Multicycle Path  
Set Multicycle Path 界面，用于设置允许多个时钟周期延时的时序路径约束，即生成
set_multicycle_path 的SDC 命令。通常情况下，两个同步的寄存器进行Setup 时序检查时，路径中组
合逻辑的Delay 必须在一个时钟周期内到达，才能满足Setup 的时序。但在某些情况下，从一个寄存器
输出到另外一个寄存器的Data 端可以允许不止一个周期的时间，且又不影响逻辑的功能。此时，可以
将这样的路径约束为多周期路径即Multicycle Path。 
点击Timing Wizard 主界面中Set Multicycle Path，即进入相关设置界面，如下图所示。

3.1.2.2 Options 设置 
用户通过Options 一栏设置查看整个设计的总体时序报告，Option 相关参数设置完成后，点击ok，

其中Report 框内参数设置报告时序检查角度显示，相关参数如下。 
 
Path Delay Type：路径延迟类型检查选择，默认值为Max_Min，暂时不可修改，即最大延迟路径
检查(setup、recovery)和最小延迟路径检查（hold、removal）系统都会在报告中分析显示。 
 
Multi Corner：路径延迟角点选择，默认值为Slow_Fast，暂不可修改，即路径延迟快、慢角点
系统都会在报告中进行分析显示。 
 
Include Ignored：勾选此项，即Timing Report 会把用户约束不进行时序分析的路径也报告出
来，即为Timing Report 的Ignored Report 分类，默认勾选。 
 
Violation Only：勾选此项，即Timing Report 只会报告显示出有时序违例的路径。如勾选此
项，则Include Ignored 为不可选状态。 
在静态时序分析中，系统按照最恶劣的情况进行时序检查，以此得出的时序收敛结果才能保证设计
工作在不同情况下都能满足时序要求。 
因此，在setup/recovery 检查时，统按照最恶劣的情况进行时序分析： 
 
在Slow Corner（慢角点）中，源时钟路径采用最大延迟Slow.Max，数据路径采用最大延迟
Slow.Max，目的时钟路径采用最小延迟Slow.Min； 
 
在Fast Corner(慢角点)中，源时钟路径采用最大延迟Fast.Max，数据路径采用最大延迟
Fast.Max，目的时钟路径采用最小延迟Fast.Min。在hold/removal 检查时，系统也按照最恶劣
的情况进行时序分析： 
 
在Slow Corner（慢角点）中，源时钟路径采用最小延迟Slow.Min，数据路径采用最小延迟
Slow.Min，目的时钟路径采用最大延迟Slow.Max； 
 
在Fast Corner(慢角点)中，源时钟路径采用最小延迟Fast.Min，数据路径采用最小延迟
Fast.Min，目的时钟路径采用最大延迟Fast-Max。

3.5.3.2 时钟树拓扑结构 
时钟树是由许多缓冲单元(buffer)及与其相互连接关系搭建的树状结构。树根表示时钟信号的源
点，叶子即时钟终端表示电路中时序器件（如寄存器）的时钟引脚。树干部分表示从时钟源点到时序器
件的时钟引脚所需经过的布线以及缓冲单元。信号从时钟源点传播到时序器件的时钟引脚的过程中，经
过多级缓冲器（数量根据设计需要而定），因此，时钟树中叶子结点的高度可能不一。时钟拓扑结构有
两种显示方式，一种是时钟树显示方式，另一种是独立时钟显示方式，两种显示方式需要点击工具栏
来切换。其中，时钟树显示方式（默认是该显示方式），如图所示。
