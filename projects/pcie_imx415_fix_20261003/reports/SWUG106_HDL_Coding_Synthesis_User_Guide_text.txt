1 概述 
本文档主要介绍了TangDynasty®（以下简称 TD 软件）软件中综合技术和硬件描述语言（HDL）的
设计编码规范，包括可综合的HDL 代码、TD 支持的Synthesis Directive、TD 综合编译选项、典型应
用示例、面积优化、时序优化、功耗优化方法。通过此文档，可帮助用户在设计过程中规避不必要的综
合问题，并充分利用TD 软件的体系结构功能。 
2 HDL 编码支持 
本章主要介绍了TD 软件中对HDL 设计编码的支持程度，帮助用户了解Verilog、VHDL、
SystemVerilog 相关语法知识。 
2.1 Verilog 编码支持 
2.1.1 功能支持 
Verilog 可用于更高抽象层次下描述行为级或结构级的电路设计，采用Verilog 进行电路描述时，
需要知晓并理解该硬件描述语言支持的相关语法与功能。TD 所支持的Verilog 语法、功能包括如下方
面： 
1. 部分变量选择 
Verilog-2001 允许用户使用变量从矢量中选择一组数据。变量选择不是由两个显式值限定的，而
是由其范围的起点和向量的宽度定义的。下表列出了变量部分选择支持符号。

2.1.6.2 case 条件分支 
 
case 语句： 
case 语句通常执行变量、常数与表达式间的比较，并选择几个并行分支中的一个。选择条件通常

为按照分支顺序依次判断其真假，并执行第一个判断为true 的分支。如果没有一个分支匹配，则执行
默认分支。对于某组信号的不同值作为分支条件可以用case 语句描述。 
wire [2:0] sel; 
wire [4:0] din; 
reg dout; 
always @(*) 
 
case (sel) 
 
 
3'b000: dout <= din[0]; 
 
 
3'b001: dout <= din[1];

4.3.3 parallel_case 
parallel_case 只在Verilog/System Verilog 生效。在casex/casez 语句中可能包含x/z 的情况，
各条件不是完全互斥时，综合工具解析时会生成优先级顺序。parallel_case 指导综合工具将该case 的
各条件视为完全独立，并行执行，主要起到忽略case 语句中隐含优先级的作用。使用该attribute 可
以降低因为优先级而产生的级数与资源。 
注意该attribute 只能在HDL 中设置,且注意标注的case 的条件必须互斥,否则会出现仿真、验
证差异问题。 
 
器件支持：支持所有器件 
 
应用对象：Verilog 代码语句:case、casex、casez 语句的条件分支

value: 无

4.3.10 keep

4.3.14 ram_style 
ram_style 指定综合工具推断RAM 时所使用的实现方式。可以通过HDL 设置，也可以通过
TCL/ADC/SDC 设置，但是由于优化过程中网表中对象名字的变化，更加推荐使用在HDL 中。 
 
器件支持：支持所有器件 
 
应用对象： 
RTL 中可以被推断为RAM 的寄存器二维数组（memory），module， module 例化处。 
Read design 后网表中的RAM instance，或RAM instance 所在的层次模块。 
 
key/value 支持 
key：ram_style  
value：（字符类型）无默认值。 
 
auto 
 
软件自行推断RAM 类型,此为默认值 
 
bram 
 
推断为block ram 
 
bram_144k 
推断为144k 的block ram 
 
dram 
 
推断为distributed ram 
 
none 
 
推断为LUT 和Reg 资源 
其中dram，bram_144k 和none 没有其他变形，直接指定即可，但是bram 允许多种变形。 
规则说明：bram{ _9k, _20k, _32k }{(fast),(power),(area)}，花括号内为可选项，可任意
组合，其中： 
– 
{ _9k, _20k, _32k }，第一个可选项指定bram 类型，不指定时由软件自行决定； 
– 
{(fast),(power),(area)}，第二个可选项指定软件优化策略，不指定时默认area。 
例如： 
bram_9k(fast)，指定9k 资源，采用fast 优化方式； 
bram(fast)，软件自行决定bram 大小，采用fast 优化方式。

1. ram_style 的可选值因不同器件而异，各器件memory 资源和限制请参见各器件的《存储资源用户

4.3.23 gated_clock 
gated_clock 指导综合工具进行门控时钟转换功能。 
常见的门控时钟逻辑为原始时钟信号和时钟使能信号通过组合逻辑驱动DFF 的时钟端口。
gated_clock attribute 加在原始时钟信号上，综合工具会将原始时钟和门控时钟控制信号转换到DFF
的时钟端和使能端，从而将门控时钟转换为有利于在FPGA 上时序收敛的等价逻辑。 
gated_clock attribute 需要与综合编译选项gated_clock_conversion 结合使用。 
注： 
1. gated_clock_conversion 的使用参见《SWUG202_TangDynasty®高级时序收敛指南》中的“EDA 工具
的属性选项介绍”章节。 
a） gated_clock_conversion 设置为off 时，综合工具不做门控时钟转换。 
b） gated_clock_conversion 设置为on 时，添加了gated_clock 为true/yes/1 的时钟信号，综
合工具对其相关的门控时钟逻辑进行转换; gated_clock 为false/no/0 的时钟信号不做门控
时钟转换。 
c） gated_clock_conversion 设置为auto 时，综合工具依据以下规则： 
– 
添加了gated_clock为true/yes/1的原始时钟信号，对其相关的门控时钟逻辑进行转换。 
– 
SDC 中添加了时钟约束的原始时钟信号，且其gated_clock 不为false/no/0，则对其相关
的门控时钟逻辑进行转换。 
– 
不满足以上条件的原始时钟信号，不做门控时钟转换。

5 HDL 编码技巧 
本章节主要介绍数字逻辑电路中常见的描述方法、技巧、功能模块等方面，帮助用户快速建立起基
于TD 的HDL 编码能力。 
5.1 表达式与操作符 
表达式出现在赋值操作符右侧、条件判断的括号中、或者在其它表达式中作为子表达式。 
表达式由操作数和操作符组成，不同的操作符会综合出不同的组合逻辑电路。 
5.1.1 合并、重复 
合并操作用 { } 操作符来表示，一般进行合并操作后，位宽为：参与合并的信号全部位宽之和。 
wire a[3:0]; 
wire b[3:0]; 
wire c[7:0] = {a, b}; 
重复操作用 { { } } 操作符来表示，重复后的位宽为：被重复信号的位宽与重复次数之积。 
wire a[3:0]; 
wire b[7:0] = {2{a}}; 
5.1.2 移位 
左移操作用 << 表示，右移操作用 >> 表示，移位后空出的位置补0。 
wire a[3:0]; 
wire b[3:0] = a << 1; 
wire c[3:0] = a >> 1; 
算术右移操作用 >>> 表示，移位后空出的位置补操作数最高位。 
wire a[3:0]; 
wire b[3:0] = a >>> 1; 
5.1.3 非、与、或、异或、同或 
按位非操作用 ~ 表示，按位与操作用 & 表示，按位或操作用 | 表示，按位异或操作用 ^ 表示，
按位同或操作用 ~^ 表示。

5.2 组合逻辑

5.2.5 避免不稳定组合逻辑环 
与稳定组合逻辑环相比，不稳定的组合逻辑环输出值会出现0、1 跳变，即，当设计出不稳定的组
合逻辑时，电路中的信号会在特定的状态下进入振荡状态。不稳定组合逻辑环违反了电路设计中的同步
原则，从而导致设计的电路出现大量问题，包括：信号不稳定，出现反复振荡，造成电路大功率消耗；
产生毛刺；时序违规等。不稳定组合逻辑环会造成设计系统极不稳定，因此在设计中要避免不稳定组合
逻辑环的构造。

5.11.4 按编码方式分类 
FSM 有限状态机除按照输入输出关系分类外，还可以采用编码方式进行分类。最著名的是二进制编
码，除此之外还有格雷编码和one-hot 编码。 
5.11.4.1 二进制编码 
顺序二进制编码，即将状态依次编码为顺序的二进制数。顺序二进制编码是最紧密的编码。 
优点：在于它使用的状态向量位数最少。例如对于6 个状态的状态机，只需要 3 位二进制数来进
行编码，因此只需要 3 个触发器来实现，节约了逻辑资源。 
缺点：翻转次数较多，功耗大；易出现毛刺；状态跳转需要过多组合逻辑电路，电路复杂，不利于
级数的优化。

5.11.4.2 one-hot 编码 
 
One-Hot 编码，又称为一位有效编码、独热码，主要是采用N 位状态寄存器来对N 个状态进行编码，
每个状态都由他独立的寄存器位，并且在任意状态时候只有一位有效。 
优点：译码简单，组合逻辑电路较少，电路可靠性较高；状态跳转简单，译码速度和编码数量无直
接关系，系统运行速度较快。

6.1.5 常数乘法优化 
在数字电路中，如果某个数据和常数相乘，可以等效地转换成移位加法。比如a*9 即a*4'b1001 就

6.1.6 硬核使用

据应用场景做面积优化。

如果某个时序路径超出较少额度，并且该时序路径上游的时序又保持很松弛的情况时，可以采用反

6.2.9 大MUX 语句优化 
大的case 语句或者索引取址语句会综合出大的MUX 逻辑，最后用LUT 来实现。一般可以认为一个
6 输入LUT 可以实现一个4 选1 MUX，那16 选1 MUX 就需要2 级6 输入LUT，而64 选1 MUX 就需要3
级，因此当case 的条件信号位宽较宽，条件分支较多时，就很容易成为时序瓶颈。如果分支中用到的
上游信号已经经过组合逻辑电路，则问题会更严重。 
对此最简单有效的方法就是插拍。比如case 条件信号6 bits，64 个分支，代表3 级组合逻辑，上
游已经过1 级组合逻辑，因此总数为4 级。如果1GHz 只允许每个时钟周期内2 级，就需要在MUX 中间
插一级。

文件名：mux_big.v 
always @(posedge clk) 
    dout <= data[addr];

6.3 功耗优化 
6.3.1 Clock gating 
Clock gating 通过控制时钟信号的跳转，减少时钟网络功耗和对应的DFF 翻转功耗，达到优化功
耗的效果。在电路中如果有某个子模块可以长时间不工作，譬如当某个模块处于用户不使能、输入不跳
变、输出不被选中的情况时，便可将其时钟关断，以此节省时钟网络翻转所带来的动态功耗。 
Anlogic FPGA 的芯片按family 进行分类时，包含有多种带使能的时钟缓冲器，可以按需在Language 
Template 里查询调用。 
 
图 6-6 时钟缓冲器显示 
FPGA 芯片的时钟资源是有限的，该限制包括全局时钟和局部时钟，因此当调用时钟缓冲时会导致
时钟信号变多，而时钟信号过多可能会导致布局合法化困难，时钟信号布线困难。注意：TD 软件目前
不支持根据用户if (clock_enable) q <= d; 语句自动推导clock gate 逻辑。

6.3.3 避免不稳定的组合逻辑环 
电路设计中，首先要避免组合逻辑环。TD 软件会在电路中检测组合逻辑环并提示warning。请在看
到warning 后仔细检查修改电路设计，去掉组合逻辑环。 
组合逻辑环有两种，稳定的和不稳定的。不稳定的组合逻辑环常见的例子有奇数个反相器组合的环
及其相似电路。不稳定的组合逻辑环会在特定的状态下进入振荡状态。通过在设计中规避不稳定组合逻
辑环可以进一步优化功耗。
